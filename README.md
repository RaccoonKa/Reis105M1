# Симулятор цифрового импульсного рефлектометра РЕЙС-105М1

Виртуальный тренажер и интерактивный симулятор портативного цифрового импульсного рефлектометра **РЕЙС-105М1**, разработанный на платформе **.NET 8 (WPF)** с поддержкой физико-математической модели кабельной линии, виртуального ЖК-экрана 128x64 и интерактивной 2D-сцены с анимацией подключения кабелей.

---

## Архитектура решения

Решение структурировано по модульному принципу в соответствии со стандартами чистой архитектуры:

```
Reis105M1/
├── src/
│   ├── Reis105M1.Core/         # Доменные модели, физ-мат модель рефлектометрии, конечный автомат
│   ├── Reis105M1.Display/      # Пиксельный буфер ЖК-экрана 128x64, отрисовка графиков и шрифтов
│   └── Reis105M1.UI/           # WPF-интерфейс, интерактивная панель, 2D-анимации кабелей и камеры
├── tests/
│   └── Reis105M1.Core.Tests/   # Модульные тесты математических моделей, задержек и состояний
├── .editorconfig
├── .gitignore
├── README.md
└── Reis105M1.sln
```

### Модули системы

1. **`Reis105M1.Core`** (`net8.0-windows`):
   - `DeviceState`: состояние питания, текущий диапазон измерений, коэффициент укорочения линии, усиление, положение измерительных курсоров.
   - `ReflectometryEngine`: синтез рефлектограмм по заданным параметрам кабеля (задержка сигнала, затухание, дефекты типа КЗ/обрыв/неоднородность волнового сопротивления, добавление гауссовского шума).
   - `MenuStateMachine`: логика переключения режимов и отклика на нажатия кнопок панели прибора.

2. **`Reis105M1.Display`** (`net8.0-windows`):
   - Монохромный виртуальный буфер 128x64 пикселей (оригинальное разрешение экрана РЕЙС-105М1).
   - Быстрый блиттер и отрисовка примитивов (линии, текст, маркеры курсоров) в растровый массив / `WriteableBitmap`.

3. **`Reis105M1.UI`** (`net8.0-windows` / WPF):
   - Интерактивная 2D-сцена на Canvas с фотореалистичной или стилизованной панелью прибора.
   - 2D-анимации подключения кабелей к разъемам с использованием WPF Storyboards и `DoubleAnimation`.
   - Кинематографический наплыв камеры к экрану прибора с помощью `ScaleTransform` и `TranslateTransform`.
   - Слой сенсорных/мышиных зон над кнопками прибора.

4. **`Reis105M1.Core.Tests`** (`xUnit`):
   - Модульное тестирование расчета задержек, расстояния до дефектов ($L = \frac{v \cdot \Delta t}{2}$), коэффициента укорочения и работы FSM.

## Запуск и сборка

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее
- ОС: Windows 10 / 11

### Сборка через .NET CLI
```bash
# Клонирование репозитория
git clone <repository-url>
cd Reis105M1

# Восстановление зависимостей и сборка
dotnet restore
dotnet build

# Запуск тестов
dotnet test

# Запуск приложения
dotnet run --project src/Reis105M1.UI/Reis105M1.UI.csproj
```
